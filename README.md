# English Unlock

An installable mobile web app for daily English conversation practice. The app includes 50 guided English questions, local learning history, sample answer coaching, speech synthesis, optional speech recognition when the browser supports it, and a 60-minute daily practice target.

## Install on iPhone

After GitHub Pages is enabled under Settings → Pages → Deploy from branch → main / root, open https://k38407960-creator.github.io/english-unlock/ in iPhone Safari. Tap Share → Add to Home Screen. Open the new English Unlock icon.

## Important limitations

- Feedback is rule-based and not a live AI teacher.
- Voice dictation depends on browser support; text entry always works.
- The activity-aware timer is an approximation, not secure proof of an hour of study.
- Learning data is saved locally on the device/browser and can be exported; there is no account sync.
- A web app cannot block other iPhone apps. A later native iOS application would need Apple's Screen Time APIs and its own authorization, and a trustworthy server-backed lesson-verification system before any unlock decision.
- Screen Time cannot make the device impossible to unlock by its owner.

No API keys or private data are published in this repository.
